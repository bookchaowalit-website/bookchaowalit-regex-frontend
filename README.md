# Regex Tester

Live JavaScript regex tester with flags and match list.

## Features
- Flags: g i m s u y
- Match list with indexes
- Highlighted matches in sample text

## Limitations
- Uses JS RegExp semantics (not PCRE/Python)
- Invalid patterns surface the engine error

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
